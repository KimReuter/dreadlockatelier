# Dreadlocks Website

Personal brand website for a premium dreadlock studio.
Editorial, cinematic design — built to feel like an experience, not a service page.

## Tech Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** — animations
- **Lenis** — smooth scroll

## Design Direction

Cinematic Organic Luxury.
Warm blacks, cream tones, natural textures.
Big typography, intentional whitespace, slow motion.

## Getting Started

```bash
npm install
npm run dev
